## Архитектура и поведение

- React/TypeScript/Vite, браузер и Telegram Mini App. Платформенные различия проходят через `src/platform/`, существующие providers/hooks и безопасные обёртки.
- Запуск: `main.tsx`; навигация/Back: `AppWithNavigator.tsx`; маршруты/guards: `App.tsx`.
- HTTP: `src/api/client.ts`; токены/refresh: `src/utils/token*`; Zustand: `src/store/`; серверное состояние: TanStack Query. Использовать существующий клиент, не дублировать refresh/CSRF/ошибки.
- `/api/cabinet/...` в dev преобразуется в `/cabinet/...` на backend:8080. Health проксируется отдельно.
- Сбой транспорта не равен отказу авторизации: не разлогинивать пользователя при временной недоступности backend.
- Клиентские permission guards не заменяют серверный RBAC. При изменении DTO/API сверять backend routes/schemas и пользовательские состояния.
- Тексты интерфейса — через i18n, ru/en/zh/fa; учитывать RTL. Не показывать пользователю сырые ключи, поля API и технические сообщения.
- `VITE_*` попадают в клиентскую сборку: секреты туда не класть.
